Privacy policy

Last updated October 27, 2026.

Workbench is a personal tool used only by its author, Malcolm MacIntyre. It has no other users.

What it accesses

With the account owner's permission, Workbench uses the Gmail API to send email and to read replies to emails it sent, and the Google Calendar API to read and create calendar events.

Where the data goes

Data from Google stays on the owner's computer. Workbench does not sell, share, or transfer it to anyone, does not use it for advertising, and does not use it to train AI models.

Google API Services User Data Policy

Workbench's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the saved token on the computer removes Workbench's access as well.
